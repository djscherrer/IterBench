\label{ch:appendix-per-iteration}

This appendix lists the full per-iteration record behind
Chapter~\ref{ch:results}: every one of the $3\times7\times3=63$
model$\times$scenario$\times$framework tasks, and within each task the
goodput and LLM spend of all eleven iterations (the baseline plus ten
refinement steps). The aggregate figures in Chapter~\ref{ch:results} are
computed from exactly these numbers; the tables here let those be checked
task by task.

\paragraph{How to read an entry.} There is one table per model, split into
seven scenario bands, with one row per framework and one column per
iteration (\textbf{Base} is iteration~000, the pre-refinement baseline).
The large number in an entry is that iteration's goodput in req/s, and the
small grey number below it is the LLM spend for that iteration (in USD,
from its \texttt{llm\_cost\_ledger.json}). The highest goodput in each
framework row is set in bold. An entry can take three forms:

\begin{itemize}
  \item a goodput value: the iteration deployed and was load-tested, and
    sustained that many req/s;
  \item \texttt{0}: the iteration completed a load test but sustained no
    goodput, either an up-but-not-serving deployment or a baseline that is
    still dead before refinement recovers it;
  \item an italic, shaded keyword: the iteration failed at a pipeline
    stage before any goodput could be measured. Note that a failed
    iteration still spends on its LLM calls, so it still carries a cost.
\end{itemize}
